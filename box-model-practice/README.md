Домашка: блочная модель (box-model-practice)

1. box-one
Модель content-box. Размеры в css (320x140) задают только сам контент, а рамки и паддинги плюсуются к ним и раздувают блок.

Расчеты:
Ширина без марджинов: 8 (левая рамка) + 40 (левый паддинг) + 320 (контент) + 20 (правый паддинг) + 4 (правая рамка) = 392px.
Высота без марджинов: 2 (верхняя рамка) + 10 (верхний паддинг) + 140 (контент) + 30 (нижний паддинг) + 6 (нижняя рамка) = 188px.
Место на странице по ширине с марджинами: 50 + 392 + 30 = 472px.
Место по высоте с марджинами: 20 + 188 + 40 = 248px.

Слои по порядку (контент -> паддинг -> рамка -> марджин):
По ширине: 320 + 60 + 12 + 80 = 472px.
По высоте: 140 + 40 + 8 + 60 = 248px.


2. box-two
Модель border-box. Тут размеры блока зафиксированы на 320x140. Паддинги и рамки не увеличивают блок снаружи, а уходят внутрь и ужимают контент.

Расчеты:
Ширина без марджинов: ровно 320px. Сам контент внутри сжался до 248px (320 - 60 паддинги - 12 рамки).
Высота без марджинов: ровно 140px. Сам контент внутри сжался до 92px (140 - 40 паддинги - 8 рамки).
Место на странице по ширине: 50 + 320 + 30 = 400px.
Место по высоте: 20 + 140 + 40 = 200px.


3. Разница между content-box и border-box
В content-box свойства width и height меняют только размер текста или картинки внутри, а рамки и отступы добавляются сверху и делают блок больше.
В border-box свойства width и height — это уже итоговый размер всей коробки, а рамки и паддинги просто съедают место у контента внутри, не меняя внешние габариты.


4. box-three
Размеры 400x160 (content-box).
Свойства записал кратко в одну строку по часовой стрелке (верх, право, низ, лево):
padding: 15px 25px 35px 45px;
border: 1px solid #5f319b; (рамка по 1px со всех сторон)
margin: 10px 20px 30px 40px;

Ширина без марджинов: 1 + 45 + 400 + 25 + 1 = 472px.
Высота без марджинов: 1 + 15 + 160 + 35 + 1 = 212px.
